# Filtering Tools

_GeoSlicer_ module to allow image filtering, as described bellow:

1. Select a _Filtering tool_.

2. Fill the necessary inputs and apply.
Available tools: Gradient/Curvature Anisotropic Diffusion, Gaussian Blur, Median, Euclidean Distance Transform, Simple Filters, Shading correction (Gaussian and Polynomial) and Ring Artifact Removal.
